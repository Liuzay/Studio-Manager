# Studio Manager Design System v1

## Foundations
- Spacing: 4, 8, 12, 16, 20, 24, and 32 px tokens.
- Radius: 10, 14, 20, 28 px, plus pill.
- Shadows: small, medium, and large elevation.
- Typography: rounded display faces with system body text.
- Motion: 160 ms fast, 260 ms normal, 520 ms slow.

## Core components
- `.btn`: primary action; variants `.secondary`, `.ghost`, `.danger`, `.good`, `.icon`, `.full`.
- `.card`: elevated content container.
- `.component-card`: compact reusable container.
- `.component-stack`: vertical rhythm utility.
- `.component-cluster`: wrapping horizontal group.
- `.badge`: small status label.
- `.empty`: empty-state message.

## Accessibility
- Minimum 44 px interactive targets.
- Keyboard-visible focus rings.
- 16 px mobile inputs to prevent iOS zoom.
- Reduced-motion support.
